# Changelog

## 1.4.0 — 2026-10-22

- Evolve the ambient mascot from a single horizontal swim into a full breach
  event: rise from water, swim on the surface, dive back, with wake and splash,
  at randomized heights and staggered timings.


## 1.3.0 — 2026-10-22

- Add the water-surface layer to mascot guidance: slow rings, jump ripples,
  splash droplets, and a subtle glass-card response.
- Keep water as CSS, not a landscape photo; respect reduced-motion and never
  intercept touches.


## 1.2.0 — 2026-10-22

- Add `references/mascot.md`: assistant avatar vs pet system, interactive and
  ambient layers, full-body clipping check, swim/jump motion and reduced-motion.
- Add mascot checks to the audit.
- Record a real iOS animation of the ambient fish.


## 1.1.0 — 2026-10-22

- Add `references/typography.md`: minimum type scale, Dynamic Type, screenshot audit.
- Raise minimums: body 15–17pt, readable captions/sources ≥12pt, decision/action text ≥15pt.
- Ban 8–10pt for information; tighten accessibility and audit checks.


## 1.0.0 — 2026-10-22

- First public generic core: Discover / Define / Deliver.
- Real iPhone screenshot workflow, state matrix, accessibility.
- Independent screenshot-only critic, calibration and 9/10 gate.
- Seed and review-validation scripts, self-check and CI.
- Synthetic example product, brief, review report and walkthrough.
- Open-source governance: private presets, licensing, redaction.
