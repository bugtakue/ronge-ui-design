# 吉祥物 / 助手化身

> 吉祥物不是宠物系统。  
> 它应该是“助手在场”的一个可见化身，不是喂养、升级、亲密度和金币。

## 1. 两种层

### 交互层：稳定可点

- 44pt 以上，最好 48–56pt；
- 完整身体必须在按钮内，不允许裁掉头、眼睛、尾鳍；
- 透明 PNG / SVG，四周留 padding；
- 必须测试 1×、2×、3× 实际尺寸，而不是放大稿；
- 有更新时加一个小光点/涟漪，不弹窗；
- 点击打开助手面板，不是聊天页；
- 面板只给：当前状态 + 一个主行动 + 一个轻退出。

### 环境层：背景里活着

- `pointer-events:none`，绝不挡点击；
- 放在内容下方，opacity 约 0.12–0.20；
- 游动 30–40 秒横穿一次，幅度小；
- 跳跃罕见（10–15 秒一次），弧线 15–25px，不遮挡标题；
- 不进入正文主要阅读区，不挡按钮；
- `prefers-reduced-motion` 时直接隐藏或静止；
- 只做视觉呼吸，不承载信息。

## 2. 状态

| 状态 | 表现 | 触发 |
|---|---|---|
| idle | 缓慢游动/轻摆 | 无提醒 |
| notice | 光点/涟漪 | 有真实新变化 |
| thinking | 尾巴加快、身体前倾 | 正在真实处理 |
| jump | 小鱼跃出、落下 | 有值得注意的更新 |
| rest | 停在底部/边缘 | 安静、夜间或减少动态 |

每个状态必须对应真实产品状态；不要伪造“思考”或“开心”。

## 3. 不能做

- 不做喂养、等级、金币、亲密度、商店；
- 不新增“助手”tab；
- 不用 3D/Blender 宠物替代 2D 品牌鱼；
- 不用 emoji 当吉祥物；
- 不把鱼固定在一个会遮挡内容的角落；
- 不让变量/按钮移动成点击目标；
- 不让背景鱼抢标题、结论或主行动。

## 4. 截断检查（必做）

用户说“鱼没有完全出来”通常不是鱼画错了，是容器裁切/尺寸太小。

- 看按钮实际截图，不看设计稿；
- 头、眼睛、背鳍、尾鳍必须完整；
- 圆的 `overflow`、图片 `object-fit`、padding 都要检查；
- 鱼在 44px 下能否辨认？不能就放大到 56–72px 或改成横向胶囊；
- 同时检查鱼和环境鱼是否被 tab bar / 安全区裁切。

## 5. 证据

- 静帧：完整鱼、点击后的面板；
- 动效：真实 iPhone 录屏 → GIF/MP4；
- 记录：size、opacity、周期、减少动态行为；
- 预览数据必须标注，不把示意当真实状态。

## 6. 水层 / 涟漪 / 水花

如果品牌鱼生活在水里，水层可以成为“活界面”的一部分：

- 水面用 CSS 渐变/重复波纹，不用山水照片；
- 低频呼吸（8–12s）、慢速水纹（18–22s）、偶尔扫光（16–20s）；
- 鱼游过时，玻璃卡可轻微起伏 1–2px，像被水波托了一下；
- 跳跃时出现 2 圈涟漪 + 3–5 个水花颗粒；
- 水花只出现 0.4–0.8s，不持续遮挡文字；
- 背景层 `pointer-events:none`，水纹不进入主阅读区；
- 减少动态时隐藏水层和跳跃，只保留静态鱼。
