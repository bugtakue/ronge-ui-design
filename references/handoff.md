# 设计与实现交接

> 设计不是截图交付。页面要能被实现、被测试、被替换，才算完成。

## 1. 设计 token

优先复用现有 token，不新增一套：

- 颜色：primary / surface / surface-muted / border / on-surface / on-surface-variant / accent / danger；
- 字体：serif 标题 / body 正文 / mono 数据；
- 间距：4 / 8 / 12 / 16 / 20 / 24 / 32；
- 圆角：小 8 / 中 12 / 大 16–22 / 胶囊；
- 阴影：只允许 1–2 档，不能每个卡片一套；
- 图片：路径、裁切焦点、遮罩、许可。

新增 token 需要写：为什么旧 token 不够用。

## 2. 组件状态

每个可交互组件至少设计：

- default；
- pressed/active；
- disabled；
- loading；
- error；
- empty（列表/卡片）；
- 长文字；
- 深色模式（如支持）。

不要只交 default 截图。

## 3. 页面状态

每个页面至少考虑：

- 有内容；
- 安静/空；
- 加载；
- 错误/离线；
- 未登录/无权限；
- 编辑/可拖动；
- 长内容/大字号。

## 4. 动效

- 150–250ms，进入可稍长，退出更快；
- 只服务状态变化：改判、展开、追踪更新、工具拖动；
- 支持 `prefers-reduced-motion`；
- 不做无意义漂浮/呼吸光；
- 触觉反馈只用于确认动作，不滥用。

## 5. 手机约束

- 390×844 基线；
- 顶部安全区 / 底部 tab bar / home indicator；
- 主按钮 ≥ 44pt；
- 底部 tab bar 不遮挡滚动内容；
- 键盘弹出时输入框与主按钮可见。
