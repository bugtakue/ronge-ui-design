# 验证与度量

审美评分不能代替用户任务验证。

## 1. 上线前

- **5 秒测试**：给 5 个人看 5 秒，问“这屏在说什么？你下一步会点哪？”  
  答不出“结论/下一步”，层级未过。
- **任务测试**：给一个真实任务（“看看这条追踪为什么改了”），观察是否找到入口。
- **对比测试**：A/B 两版，问“哪版更愿意点？为什么？”，不追求统计显著。
- **可读性**：大字号、低对比、户外光线下复测。

## 2. 上线后

- 主行动点击率 / 完成率；
- 首屏到详情页的到达率；
- 退出动作使用率（过高说明打扰）；
- 追踪提醒的打开/关闭比；
- 用户原话反馈，不只看点赞。

## 3. 不能做的事

- 用“我觉得好看”替代任务完成率；
- 用 AI 评分替代真实用户；
- 把设计示意数据当真实效果；
- 没有埋点时编造指标。
