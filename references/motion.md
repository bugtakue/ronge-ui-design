# 动效

动效不是装饰，是状态变化的语法。

## 1. 允许的动效

- 结论改判：旧结论淡出/划线，新结论落下；
- 追踪更新：新事实进入、影响展开；
- 工具整理：拖动、让位、吸附；
- 页面转场：进入 200–250ms，退出 150–200ms；
- 反馈：按钮按压、保存成功、错误提示。

## 2. 不允许

- 无意义的呼吸光、漂浮、粒子；
- 每个卡片都做 hover/float；
- 超过 300ms 的阻塞式动画；
- 用动画掩盖加载/错误；
- 因动效导致文字被遮挡或按钮移位。

## 3. 实现

- CSS transition 优先，时长/曲线用 token；
- 复杂路径/视频只在有真实生成管线时使用；
- 支持 `prefers-reduced-motion`；
- 触觉反馈只用于确认（保存、改判、错误），不滥用。

## 4. 验收

- 录屏看 0.25×、1×；
- 检查动效结束后的静态帧是否与设计截图一致；
- 关掉动效后页面仍然成立。
