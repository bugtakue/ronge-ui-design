# 无障碍

设计稿不只要“看起来正常”，还要在小字、大字号、低视力和不同输入方式下成立。

## 1. 对比度

- 正文 ≥ 4.5:1；
- 大字号（≥18pt regular / 14pt bold）≥ 3:1；
- 关键旧状态、说明、tab 标签不能低于 3:1；
- 不用颜色单独表达“好/坏”：同时给方向词（↑/↓、更稳/更难）。

## 2. Dynamic Type

- 正文 15–17pt；说明/来源 ≥12pt；影响判断/行动的文字 ≥15pt；
- 8–10pt 禁止承载用户需要读的信息；
- 正文使用可缩放字号，不写死 px 到无法放大；
- 大字号下标题换行、按钮不被推走、底部不被 tab 遮；
- 至少测试 extra-large / accessibility-large；
- 截断时优先保留结论和主行动，不保留装饰标签。

## 3. VoiceOver

- 图标按钮必须有可读标签，不读“arrow_forward”；
- 旧结论/新结论读成一个完整判断，不读成两个孤立词；
- 图有 alt 或标为装饰；
- 顺序：标题 → 来源 → 影响 → 结论 → 主行动 → 退出。

## 4. 触控

- 主按钮 ≥ 44pt；
- 文字链也要有 ≥ 44pt 热区；
- 底部 tab 不与内容重叠；
- 长按拖动要提供替代操作（菜单/按钮）。

## 5. 动效

- 支持 `prefers-reduced-motion`；
- 不做闪烁、快速缩放、无意义漂浮；
- 动效有明确开始/结束，不阻塞操作。

## 6. 测试

- 模拟器：大字号、深色模式、VoiceOver 基础朗读；
- 真机：字体缩放、对比度、真实光线；
- 截图存证，不靠“应该没问题”。
