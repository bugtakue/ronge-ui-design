# RONGE 方法全文

## 0. 为什么需要它

模型是下一词预测器，默认会选“最可能让所有人满意”的设计：更多卡片、更多解释、更安全的布局。
这就是 AI slop：正确、完整、没有记忆点，也没有点击欲。

RONGE 不是“再加一层美化”，而是用三步把平均答案打散：

1. **Discover**：先做多个真正不同的方向；
2. **Define**：让独立评论员只看截图，按顶级工作室标准打分；
3. **Deliver**：删掉不产生价值的元素，只留一个主角和一扇门。

## 1. Discover

### 1.1 先写 brief

```text
产品：
这一屏唯一要完成的事：
用户此刻的处境：
用户看完后应该产生的判断/动作：
不能动的东西：
这次要验证的审美方向：
```

写不出“唯一要完成的事”，先不要画。

### 1.2 seed strings

先生成随机串，再从串里的结构决定设计方向：

```bash
LC_ALL=C tr -dc 'A-Za-z0-9' </dev/urandom | head -c 48
```

可用的映射示例：

- 数字密度高 → 做页码/刻度/编号节奏；
- 连续辅音多 → 更硬、更编辑、更少圆角；
- 重复字符 → 重复元素、网格、印章；
- 元音多 → 更松、更圆、更留白。

随机串不显示在 UI 上；它只用于打散默认选项。每个方向记录 seed，便于复盘。

### 1.3 三个方向

至少三个，每个方向必须有：

- 名字（A/B/C 不够，要有一句视觉主张）；
- 具体参照（杂志改判、拍卖目录、装备栏、批注纸、山水落款）；
- 一个不妥协的选择（例如“整屏只留一个深色块”“图只做地面”）；
- 真实 iPhone 截图。

方向之间要能“眯眼看”区分：去掉颜色、字号，只剩骨架还能看出不同。

### 1.4 图像与动效

文章建议用图像生成、Shader、3D、循环视频。原则：

- 图必须承担语义（来源、情绪、地面、证据），不能只是装饰；
- 没有图像/视频工具时，用真实资产或让用户提供，不要用 CSS 假图；
- 动效只服务状态变化（改判、追踪更新、展开），不做无意义漂浮；
- 任何生成图都要标注 preview，并确认版权/授权。

## 2. Define

### 2.1 独立评论员

- 新上下文子代理；
- 只看截图，不看代码、不看实现、不看旧评论；
- 想象顶级工作室执行该方向；
- 给 0–10 分和最大 2–3 个差距；
- 检查模板感、假数据、假按钮、过度解释。

提示词见 `design-critic.md`。

### 2.2 校准（可选但推荐）

文章建议用“五张图排名”做更客观的评审：

- 4 张同方向的专业案例 + 1 张你的截图；
- 让评论员按“打磨程度/品味”排名，而不是笼统说好不好看；
- 如果候选排不进前 2，先别谈 9 分。

也可以请两个独立评论员；分数取区间，不取最高分。

### 2.3 复评规则

| 分数 | 动作 |
|---:|---|
| 9–10 | 进交付；仍需用户确认 |
| 7–8.9 | 按 top_gaps 做结构性修改 |
| 5–6.9 | 有明显问题，回 Discover 重排 |
| <5 | 重做，不磨皮 |

## 3. Deliver

### 3.1 一屏一主角

- 只能有一个最大字号的主角；
- 结论/影响要比引子更重；
- 图、按钮、标题不能同时最重；
- 遮住 logo 还能看出这是该产品的判断。

### 3.2 一扇门

- 一个主行动，标签是“动词 + 结果”；
- 退出动作明显更轻；
- 没有假按钮；
- 用户点之前知道会得到什么。

### 3.3 先影响后变量

- 先说“这对你意味着什么”；
- 再说哪个变量/事实导致变化；
- 旧结论与新结论在同一根轴上；
- 同一件事不要讲三遍。

### 3.4 图与留白

- 图要么是证据的现场，要么是页面的地面；
- 上缘可淡入纸面，下缘不能被 tab bar 硬切；
- 留白托住判断，不在顶部/底部堆死白；
- 首屏不要以被切一半的工具卡收尾。

### 3.5 删元素

至少删 3 个，写下：

```text
删掉：
因为：
删掉后用户损失：
```

没有损失，就不要加回来。

## 4. 100 分评分卡

| 维度 | 分值 | 看什么 |
|---|---:|---|
| 第一眼记忆点 | 20 | 遮住 logo 还知道是谁？有一句人话？ |
| 信息层级 | 20 | 主角唯一？结论赢过引子？ |
| 因果/影响 | 20 | 用户看见“这对我意味着什么”？ |
| 动作 | 15 | 只有一扇门？标签明确？ |
| 工艺 | 15 | 图、字、留白、安全区、对比度 |
| 克制 | 10 | 删掉了不产生价值的元素？ |

**90 分 = 独立评审 ≥9/10 + 真实 iPhone 截图 + 删除清单 + 用户确认。**

## 5. 反模式

- AI 聊天框首页；
- 卡片瀑布；
- 三个以上同权按钮；
- 假按钮 / 假图表 / 假数据；
- 抽象节点图没有变量、没有影响；
- 图抢结论；
- 顶部大空、底部切卡；
- 8–9pt 关键文字；
- 用内部术语解释产品；
- 强行金句、古诗、宠物、无来源洞察。
