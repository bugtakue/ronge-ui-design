# 页面配方

> 通用配方；产品专属规则读 `presets/`。每页仍然走 RONGE 三阶段。

## 1. 提醒 / 洞察页

- **唯一任务**：让用户看见一个变化，并知道下一步。
- **顺序**：助手在场 → 新事实 → 实际影响 → 新结论 → 一个主行动。
- **反模式**：抽象图表、变量罗列、结论讲三遍、多个同权按钮。
- **必查**：来源/时间/角色；旧结论可读；退出动作更轻。

## 2. 安静 / 空状态

- **唯一任务**：没有内容时不假装有内容，让工具桌面可用。
- **顺序**：一句安静说明 → 工具桌面 → 可添加工具。
- **反模式**：硬塞案例、假推荐、空白页、强制引导。
- **必查**：用户知道“现在没内容”不是“坏了”。

## 3. 编辑 / 桌面

- **唯一任务**：让用户把工具摆顺手。
- **顺序**：编辑态 → 拖动/添加/删除 → 保存。
- **反模式**：工具卡被 tab 切、无空位、无退出、长按无替代。
- **必查**：44pt、空位、工具架、保存/取消。

## 4. 决策输入页

- **唯一任务**：把选项和关键未知说清，并让用户确认成本。
- **顺序**：问题 → 选项 → 关键未知 → 成本 → 开始。
- **反模式**：替用户预设答案、隐藏点数、直接推演。
- **必查**：3 个选项、可编辑、成本可见。

## 5. 决策结果页

- **唯一任务**：让用户看清三个选项的因果与代价，而不是拿一个排名。
- **顺序**：结论摘要 → 对比 → 主链/暗点 → 1/3 年影响 → 下一步验证。
- **反模式**：排名、确定性承诺、没有共同未知、没有下一步。
- **必查**：可逆性、机会成本、停止条件。

## 6. 追踪详情

- **唯一任务**：哪条追踪、什么变了、对结论的影响。
- **顺序**：来源 → 变化 → 影响 → 是否重看 → 时间线。
- **反模式**：只给结论、没有时间、没有角色。
- **必查**：过去 vs 现在；旧结论可读。

## 7. 登录 / 免费试跑

- **唯一任务**：让用户知道免费规则和下一步，不伪造已登录。
- **顺序**：价值 → 规则 → 登录/试用 → 退出。
- **反模式**：假免费、隐藏扣点、强制绑定。
- **必查**：只给一次、后端防刷、未登录有退路。

## 8. 通知 / 设置

- **唯一任务**：只让用户管三类通知，不堆开关。
- **顺序**：通知类型 → 频率/开关 → 权限状态。
- **反模式**：权限拒绝后无退路、默认全开、营销混入。
- **必查**：系统权限拒绝、App 内开关、真实设备验证。

## 9. 结果 / 分享

- **唯一任务**：让结果可读、可带走、可回到原问题。
- **顺序**：结论 → 关键证据 → 分享/保存 → 回到结果。
- **反模式**：把分享做成下载页、丢失上下文、没有隐私边界。
- **必查**：脱敏、来源、可撤回。
