# Synthetic examples

These examples calibrate the skill. They contain no real brand, user or screenshot.

- `synthetic-brief.md` — fictional product “Latch”: brief and three directions.
- `synthetic-review.json` — example critic scores for `scripts/validate_review.py`.
- `synthetic-walkthrough.md` — a full loop from brief to next revision.

Keep at least one synthetic example in the public repo so the method does not depend on one product.
