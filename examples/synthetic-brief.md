# 合成示例 · Latch

> 虚构产品，仅用于演示 RONGE 流程，不含真实品牌或用户。

## Brief

```text
日期：2026-01-01
页面：Latch 首页
产品一句话：Latch 帮自由职业者决定“这个月接不接这个项目”。
这一屏唯一要完成的事：让用户看见一个新项目对本月现金流的影响，并决定是否打开比较。
用户此刻的处境：手里有两个项目询价，但不知道接哪个会让月底更紧。
用户看完后应该产生的判断/动作：先打开比较，不立刻答应。
不能动的东西：金额单位、项目名、用户已保存的报价。
这次要验证的审美方向：留白编辑感，不用 dashboard 卡片。
用户原话：“我不想看一堆仪表盘，我想要一个人告诉我这个月会不会紧。”
```

## 三个方向

```text
A · 留白编辑
视觉主张：像一封写给自己的现金流短笺，只有一个数字和一个判断。
具体参照：独立杂志的每月财务专栏。
不妥协的选择：不放图表，只用一个数字和一句影响。

B · 对比账本
视觉主张：左边本月、右边接下项目，两个数字直接对照。
具体参照：一本摊开的账簿。
不妥协的选择：只用一条竖线分隔，不做两张卡片。

C · 画面叙事
视觉主张：一张深夜工作台的照片，上面压一句现金流判断。
具体参照：纪实摄影集的内页。
不妥协的选择：图片占上半屏，文字只留一句。
```
